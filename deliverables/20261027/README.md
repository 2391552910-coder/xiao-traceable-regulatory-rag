## 研究范围与结果

研究覆盖 20 家公司、60 道问题；400 个计划输出中有 386 个有效输出由两位评分者独立评分。G2 双路检索相对 G1 合并检索的已观测配对公司宏均分差为 +0.250/8，探索性 95% 公司聚类区间为 [0.167, 0.333]；G3 相对 G2 的差为 −0.008，未显示稳定增益。分析方案属于探索性，不是预注册确认性实验。

复现清单记录 25 页、13 幅图、19 张表、29 条参考文献；本稿版本新增大模型调用 0 次、人工标签 0 条。复现 ZIP 含 118 个条目，其中 117 个文件受清单逐项校验；未包含原始年报 PDF、API 密钥或外部账户凭证。复算需要仓库中已有的冻结输入和源码模块。

## 解释边界

两位评分者的 232 项维度评分分歧尚未仲裁；论断—证据独立盲审记录尚未收到人工判断；法规适用时点和论断级语义支持没有得到完整独立验证。因此文中结论限定为当前样本、任务和评分口径下的探索性观察。作者、单位、基金及其他投稿声明须由作者据实确认。
