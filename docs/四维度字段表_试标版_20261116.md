# 年报四维度字段表 试标版

版本：2026-11-16。用途是指导年报知识库抽取、试标和问题设计。字段是待抽取的事实类型，不表示每家公司的年报均披露了这些内容，也不表示已完成抽取或人工确认。四维名称沿用项目定义；示例线索仅用于定位，必须回到原文核对。

## 一 通用事实与证据字段

一条记录对应一个可独立核查的事实；同一表格中不同成员、日期或事项应拆成多条，必要时由 event_id 关联。单项事实可关联多个维度，以 primary_dimension 标明主要归属，related_dimensions 保留其他关联。

| 字段 | 类型 | 填写规则 |
| --- | --- | --- |
| fact_id | 字符串 | 事实候选唯一 ID；复核修改值时保留版本历史 |
| company_id、company_name、report_year | 字符串、年份 | 使用年报主体与报告年度；子公司或人员作为事件主体单独记录 |
| primary_dimension、related_dimensions | 枚举、列表 | 主维度取 D1–D4；其他维度可空 |
| field_code、field_name | 字符串 | 使用本表稳定字段代码及名称；一个记录一个字段值或一组紧密关联值 |
| value、value_type、unit | 字符串或结构化值 | 忠实保存原值和类型；数字保留单位、百分比口径，名单保留姓名与角色 |
| reporting_period、event_date | 字符串、日期或空 | 报告期、任期、事项发生日分别记录；只有原文支持时才填具体日期 |
| entity_role、entity_name | 字符串 | 公司、子公司、董事、审计机构、评级机构等实际主体，原文未说明时留空 |
| disclosure_status | 枚举 | `disclosed_affirmative` 明确肯定、`disclosed_negative` 明确否定、`not_disclosed` 已审范围未披露、`parse_failed` 解析失败、`unresolved` 待核实 |
| source_role | 枚举 | `company_disclosure` 公司披露、`audit_opinion_reported` 年报记载的审计意见、`third_party_reported` 年报转述的第三方评价、`other_reported` 其他来源角色；并非独立验证外部原件 |
| evidence_id、doc_id、source_sha256 | 字符串 | 关联原文证据、文件身份及原文件 SHA256 |
| physical_page、text_snapshot_id、text_sha256、spans、quote | 数字、字符串、区间、引文 | PDF 物理页从 1 起；页文本字符区间从 0 起、半开；引文与冻结文本快照对应，跨页分段保存 |
| table_context | 结构化对象或空 | 表格事实保存表名、表头、单位、行列、续表关系及必要页码 |
| label_source、review_status、review_note | 枚举、枚举、文本 | 区分自动候选与人工确认；候选默认 `pending`，记录待确认理由，不预填人工结论 |

`not_disclosed` 必须注明审查范围；仅候选检索未找到时标记“未检出/待查”，不能升级为已审范围未披露。原文中的“不适用”“未发现”等分别保留原话及披露主体，不自动等价于零、无事件或事实不存在。冲突值、时间限定和来源角色均须保留。

## 二 D1 信息披露质量

| 字段代码与名称 | 事实定义与值类型 | 年报定位线索 | 证据与判断边界 |
| --- | --- | --- | --- |
| D1_REPORT_RELEASE 年报披露日期 | 年报披露日期；日期 | 公司信息、信息披露及备置地点 | 原文标示的日期与年报封面日期、董事会批准报出日期分别保存，不互相替代 |
| D1_DISCLOSURE_EVENT 信息披露事项 | 公司披露的具体事项、类别与描述；文本或结构化事件 | 重大事项、临时公告、信息披露索引 | 记录事项主体与报告期；只表示年报记载 |
| D1_CORRECTION 披露差错及更正 | 差错类型、相关事项和更正说明；文本或事件列表 | 前期会计差错更正、公告更正、监管问询 | 区分公司解释、差错与监管措施；“不适用”照原文保存 |
| D1_DISCLOSURE_INQUIRY 披露问询 | 问询机构、内容、日期及回复状态；事件列表 | 问询函、年报问询、回复公告 | 没有披露具体日期则留空；保存原文与对应索引 |
| D1_DISCLOSURE_MEASURE 披露相关监管措施 | 对信息披露事项的监管或纪律措施，含机构和对象；事件列表 | 监管措施、行政监管、纪律处分 | 区分公司、个人及子公司，记录处罚与监管措施的真实类型 |
| D1_DISCLOSURE_TIMELINESS 披露时效证据 | 原文明确披露的事件时间、公告时间及期限依据；日期组合 | 报告披露时间、公告索引、延迟披露 | 年报只给报告年度不足以判断及时；须另有事件日期、实际公告时间和适用期限依据才能计算或判断 |
| D1_DISCLOSURE_SCOPE 披露范围及限制 | 报告明确说明的披露范围、遗漏原因或保密说明；文本 | 重要提示、披露豁免、风险提示 | 只能记载实际说明，不由章节存在推断信息全面完整 |

## 三 D2 董事会治理有效性

| 字段代码与名称 | 事实定义与值类型 | 年报定位线索 | 证据与判断边界 |
| --- | --- | --- | --- |
| D2_BOARD_MEMBER 董事会成员 | 董事姓名、职务、身份及任期；人员列表 | 董事、监事、高级管理人员情况 | 保存现任/离任和任职起止日期；不要把跨期名单合并成同一时点 |
| D2_INDEPENDENT_DIRECTOR 独立董事 | 独董姓名及任期；人员列表 | 独立董事履职、董事会构成 | 仅标记原文明确身份，名单和期末人数可有不同统计口径 |
| D2_BOARD_COUNTS 董事及独董人数 | 董事人数、独董人数及统计时点；整数 | 公司治理、董事会成员情况 | 以同一时点人数为准；原文未提供时不擅自从不完整表格推算 |
| D2_INDEPENDENT_RATIO 独董占比 | 同一时点独董人数除以董事总数，或原文明确披露的比例；百分比 | 董事会构成、独立董事 | 派生值记录分子、分母、时点及计算规则，分母为零或缺失时不计算 |
| D2_BOARD_MEETINGS 董事会会议 | 董事会会议次数、日期和会议事项；整数或事件列表 | 董事会会议情况、会议召开情况 | 区分报告期召开次数和表格中逐次会议，保留报告期 |
| D2_ATTENDANCE 董事出席 | 每位董事应出席、亲自出席、委托及缺席次数；整数或结构化表项 | 董事出席董事会及股东大会情况 | 带表头、姓名、时间和会议类型，核对跨页续表；不将不同统计口径混算 |
| D2_COMMITTEE 审计及其他专门委员会 | 委员会名称、成员及会议/履职事项；人员或事件列表 | 专门委员会、审计委员会履职 | 委员会成员变化和任职日期分开记录；审计委员会不等同内审部门 |
| D2_INTERNAL_AUDIT_COORDINATION 内审协同披露 | 董事会或审计委员会与内审部门协调事项的明确披露；文本 | 审计委员会、内部审计部门、沟通情况 | 记录披露的行动与机构，不据简单共现自动计算协同度或有效性 |

| D3_REMEDIATION 缺陷整改 | 整改措施、状态、期限与原文披露的效果；事件列表 | 内控缺陷整改、整改计划 | 保存公司披露的整改结果与时间，不能自动认定独立验证通过 |

## 六 试标操作与字段验收

1. 在年报原文定位事实，记录公司、年度、PDF 物理页、文本快照及原文引句；表格保存必要表头与单位。
2. 选定字段代码，填写候选值及披露状态，登记主体、时间、来源角色与取值口径。派生字段保存计算输入及规则。
3. 将候选标记为待人工确认，记录待核对事项，例如表头是否跨页、任期是否覆盖报告期、同一事项是否有多处矛盾、第三方机构是否明确。
4. 人工核对原始 PDF 后记录实际确认人、时间、处理决定和原因；有分歧时保留原判断。只在此之后把对应记录更新为人工确认。
5. 在预先指定的页面或章节范围内枚举应抽取事实，才可计算该范围抽取召回；仅抽查系统已提取记录只能估计候选正确性。

字段示例和现有历史候选均用于试标定位；最终 gold 以人工确认的原文证据和实际记录为准。事实表、证据表和问答标注按 [标注规范](标注规范.md) 关联，不能将 AI 候选直接写成人工 gold。
