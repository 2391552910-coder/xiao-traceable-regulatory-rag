已实现并验证的流程
- scripts/fetch_annual_reports.py：支持 --source-dir 从已有文件夹导入，完全不发网络请求。
  没有 --source-dir 时从巨潮获取；每次写入新目录，不覆盖 data/companies/download_report.csv。
- 从完整年报候选中排除摘要、英文、季度/半年报、错误公司及错误年度；保留公告候选和版本选择。
  在记录的公告时间窗口内选择最新完整修订版。窗口固定为报告年度次年的 1 月 1 日至 12 月 31 日，
  不是宣称此后的修订不存在，也不自动将最新版本追溯到历史事件。
- 下载或导入后检查 PDF 结构、公司名、股票代码、首页正文的主要报告年度及摘要身份。
  同代码/年度有多份本地文件时标记版本歧义，不随意选取；身份不确定的文件不进入事实提取。
- 保存来源 URL（本地导入为源文件 URI）、报告年度、已知公告日期、PDF SHA256、大小和页数。
  本地源文件没有公告日期时保留为空，不用文件修改时间冒充公告日期。
- scripts/extract_annual_facts.py：重新检查 PDF 身份及哈希，逐页保存提取文本。
  候选保存 1-based 物理 PDF 页码、页文本字符区间、引句 SHA256、源 PDF SHA256。
  页文本以 UTF-8 原样保存，避免 Windows 换行转换改变哈希和定位。
  扫描空页标记 needs_ocr；未命中某维度不作为该事实不存在或公司表现良好的证据。
  生成 fact_review.csv，复核人、正式事实、事件日期和复核理由保持待填，不虚构专家判断。
- scripts/recover_and_extract_annual_reports.py：先导入本地现有 PDF，可选择仅下载缺失公司的报告，
  合并到新的来源清单后提取候选；原下载清单保持不变，所有新目录拒绝覆盖。
- scripts/recover_annual_reports_local.ps1：Windows 本地入口，创建单独 .venv-data，
  安装 requirements-data.txt 并调用上述流程。本轮未进行 Windows 实机验证。

本地项目使用
在 xiaolun 项目的本地根目录（取得本次代码后）运行 PowerShell：

  .\scripts\recover_annual_reports_local.ps1 -SourceDir "原来保存年报的文件夹"

如只恢复已有文件，上述命令不发起年报网络请求。
如还需下载缺失原文，显式加 -AllowDownload：

  .\scripts\recover_annual_reports_local.ps1 -SourceDir "原来保存年报的文件夹" -AllowDownload

Python 通用入口：

  python -m pip install -r requirements-data.txt
  python scripts/recover_and_extract_annual_reports.py \
    --source-dir "/path/to/original/pdf/folder" \
    --out-dir results/runs/annual_local_NEW
