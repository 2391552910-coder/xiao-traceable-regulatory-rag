# 年报问答开发集规模评估与补标建议

现有26道用户确认题目覆盖19家公司、2024年年报及四个维度，适合连接切片、检索和重排流程，开展小规模开发诊断。它们已暴露于题目设计和系统开发，不适合作为独立最终测试集。

当前分布为D1六题、D2七题、D3六题、D4七题。D2七题均涉及董事会会议次数或相关事项；D3至少四题涉及内控审计意见；D4五题涉及ESG评级，另有信用评级和奖项。均为可回答题，题型、表格和证据不足情况覆盖有限。每题只确认一个支持证据方案，未穷尽其他相关片段，也未形成完整的相关与不相关候选判断。检索运行应报告已确认目标证据覆盖，未判断片段不能自动视作不相关。

## 追加标注建议

保留现有26题为开发集。另以80至120道新增人工确认题为独立留出问题集的初始工作目标，可先按每维20至30题盘点原文证据和标注成本，再在查看测试结果前确定最终规模。此数字不是统计功效保证，也不是强制均衡配额；D4若年报缺少相关资料，应记录缺失和可回答题量，不靠编造外部事实凑数。

- D1：信息披露更正、监管问询、披露主体和时间条件，保留事发时间与年报披露时间区别。
- D2：董事或独董名单及任期、出席情况、专门委员会、会议及跨页表格，减少同一种“会议次数”题的重复。
- D3：内控缺陷、整改、审计主体和意见类型，以及公司和子公司事项归属。
- D4：外部评价、评级机构、奖项授予主体与年报转述边界；必要时增加明确证据不足的问题。
- 四维均补充字段集合、表格数值、多证据和证据不足类型，分别登记可回答性与需要的证据组。

问题族、同一事项和重叠证据按连通组先划分再冻结；不能把开发题改写后放入测试集。同一批年报可共享给开发和留出问题，但结果只能解释为共享语料条件下的留出问题表现。如需评价未见公司的泛化，应另行核验此前未暴露的公司年报并按公司隔离。

候选池合并不同切片及检索方法的结果，进行人工相关性判定和原文补搜，记录候选池深度与未判比例；多证据题要保存必需证据组和替代支持方案。为报告更完整的Precision或nDCG，需对比较系统评价范围内的候选进行充分判断，未判和无法判断不得直接按负例计分。
