## 决定

当前论文的近阶段计划确实过于复杂：早期清单把双源RAG主稿、表格/跨页续表解析、跨模型、跨年和Agent扩展并列为必做，实际上对应至少五个不同研究问题。当前只推进一条主线：完成既有双源RAG受控比较的证据审计、结论校准和可复现交付；其他方向作为独立后续课题，不为增加实验数量而并入当前稿。

这里的“收缩”是范围收敛，不是降低论文标准。当前交付记录为主实验计划180个回答、获得147个供应商输出；全部条件355/400个可评分回答。G2−G1公司宏均分差+0.228/8（41对，20,000次公司聚类bootstrap区间[0.110, 0.355]），但缺失端点全题敏感性界[-1.508, 1.292]跨零。因而正文只能报告观察到的配对结果和缺失局限，不能写成完整计划题集上的确定优势。0–8评分也不等于答案准确率；现有主实验没有题目对齐的检索相关性金标准，不能据此报Precision/Recall/F1。

## 已发表论文怎样实现，能借鉴什么

| 论文 | 发表工作实际做法 | 对当前项目的参考 |
|---|---|---|
| KBS, *Retrieval augmented generation using engineering design knowledge* (2024) | 聚焦一个任务：从专利句子识别/生成显式工程关系；建立375,084个关系样例、微调任务模型，再在4,870件风机专利上形成超过293万条事实的知识库，并演示RAG用例。 | 短通信不等于低验证要求。先把单一方法主张做扎实，RAG演示不能替代主任务指标。 [论文](https://www.sciencedirect.com/science/article/pii/S095070512401044X) |
| Information Sciences, *Closing the acronym gap in educational retrieval with ontology-guided augmentation* (2026) | 针对缩写导致的检索失败，比较查询时扩展、索引时增强及组合，在约1万份文档上报告nDCG、Recall、Success，并作查询配对bootstrap。 | 用一个清楚的失效原因、少数定向干预和与检索阶段匹配的指标。无需复制其教育语料规模。 [论文](https://www.sciencedirect.com/science/article/pii/S002002552600112X) |
| ARQA, EACL Industry Track (2026) | 年报表格与文本问答基准，约2,500题、十个财年、Lookup/Arithmetic/Insight三类；自动生成后确定性复算并由领域专家审核。 | 年报研究应把问题类型、答案、原文证据绑定，数值题优先确定性复算。它是会议基准，不是期刊门槛。 [论文](https://aclanthology.org/2026.eacl-industry.63/) |
| CFQA, Financial Narrative Processing Workshop (2026) | 50家公司、500题、五类任务，人工标注答案并绑定年报；示例比较RAG与无检索基线，并分别判断答案匹配与证据支持。 | 评分维度要分开：答案内容得分不能替代检索命中或证据支持。它也是研讨会论文，供方法设计参考。 [论文](https://aclanthology.org/2026.fnp-1.3/) |
| Neurocomputing, IIER (2025) | 将多文档片段的结构、关键词和语义联系构造成图，再通过证据链检索处理多跳问答；作者稿在四个问答数据集上报告答案 Accuracy、EM、F1，并比较多种检索基线。 | 可借鉴区分检索组织与答案指标；本项目尚无同等答案金标准，不能直接套用这些指标或声称实现图检索。[期刊版](https://doi.org/10.1016/j.neucom.2025.130931) / [作者稿](https://arxiv.org/abs/2408.02907) |
| Neurocomputing, AIR-RAG (2026) | 提出自适应迭代检索方法，在六个QA/事实核查基准上比较多类方法，报告跨基准结果。 | 只有把迭代算法作为核心新贡献，才需要承担多基准与强基线的成本；不能把它当作任何RAG论文的通用清单。 [论文](https://www.sciencedirect.com/science/article/pii/S0925231225029443) |

IIER版本差异核查：arXiv v1 的表1给出2WikiMQA的IIER Accuracy 84.8、KGP 69.8，正文称提高15%；期刊页面摘要称提高9.6%。尚未核对期刊正式表格及基线口径，不能断定差异来自计算方式或实验变更，不应将该数值直接写入本稿。

这些论文的实验规模差别很大，关键在于“主张—干预—评价指标”匹配，而不是统一追求同样的模型数、年份数、Agent数或图表数。上述会议论文只用于年报问答评测设计参照，不代表目标期刊的录用标准。

1. **固定一个问题。**在当前数据、检索语料和服务设置下，比较双源分路检索与合并候选检索，观察回答评分和证据供给变化。把研究结论限定在已观察的配对样本、评分量表与固定服务范围内。

## 后续方向的启动条件

- **表格与跨页续表：**若单独研究解析/证据保留，可使用已有参考或确定性构造的样例比较普通解析与续表感知方法，并如实限定参考范围和指标含义。它不是当前双源RAG主结果的附加章节。
- **跨模型：**只有要声称模型无关或跨厂商泛化时，才另设同数据、同检索证据、可比提示和明确模型版本的对照。
- **跨年度：**只有要声称时间迁移时，才冻结不同年份语料、法规有效时点和不泄漏的测试问题。
- **Agent：**只有要声称迭代决策有效时，才做调用数/token预算匹配的一次检索或固定扩展基线；已有小样本只作探索性结果。

每次只启动一个由论文主张触发的扩展。完成当前稿不需要把这些扩展全部做完。
