## 2. 检索标注对象与候选池

给定评价查询、维度、事件/适用时点和冻结语料，标注能支撑该查询的原始证据区间。将法规要求、公司事实和案例证据角色分开，按来源版本和条款定位。

候选池由 BM25、BGE-M3、Qwen3、混合检索的结果去重合并，加入人工补搜和随机负例。两名标注者不见检索器排名、分数和预标答案；对漏检来源做补充检索。召回指标须说明基于池化已判证据，不能宣称已枚举全库全部相关条款。

采用分级相关性：

| 等级 | 标准 |
| --- | --- |
| 2：直接支持 | 内容回答核心问题，证据角色与时间适用性正确 |
| 1：辅助支持 | 提供必要定义、上下文或补充依据，但不能独立支持核心结论 |
| 0：不支持 | 主题相近、错误主体/时间、角色不符或内容无关 |
| U：无法判定 | 缺失全文、适用时间未知或专业争议尚未仲裁 |

保存 query_id、query_family、dimension、event_date、doc_id、version_id、clause_no、原文字符区间、chunk_id、relevance、reason 和 annotator_id。chunk_id 用于原型兼容，原文区间用于条款/滑窗共用评测。召回主口径使用等级 2，等级 1 做辅助分析；分级 nDCG 使用 0/1/2。U 不当作负例，须处理或报告未判比例。

当前 loader 的 relevant_chunk_ids 是二值集合；正式分级 qrels 和区间映射待实现，不能将计划字段当作已支持格式。

## 3. 人工复核与一致性

1. 先在开发查询上做小规模试标，修订歧义规则，然后冻结正式规范。
2. 两名具备证券监管/公司治理理解能力的标注者对正式查询候选池独立标注，不看 AI 标签或彼此答案。
3. 二值“直接支持”使用 Cohen's Kappa，三级相关性另报告加权 Kappa；同时报告一致率、类别分布和样本量。
4. 报告全局、分维度及低一致性查询，不只报告均值。Kappa<0.6 作为本项目复核触发线，检查小样本、类别偏斜和规则问题，不能直接删除困难查询。
5. 分歧由第三名人员仲裁，保留双方原标签、理由、仲裁结果和日期。更新后的标签不用于冒充仲裁前一致性。
6. 人工尚未完成时使用明确来源标签，不自动将 AI 候选文件重命名为人工最终 gold。

规划正式检索集至少 200 条，按语义问题族分隔开发/最终测试。现有 40 条已被开发过程使用，不能再次宣称为未见测试集。

## 4. 双源证据样例复核

本规范的人工复核服务于“年报 PDF 与法规文件分别检索，再生成带来源依据的评价内容”这一评测目标，不要求把所有公司年报穷尽整理成结构化事实库。对每个正式评测问题，核对并记录：

- 年报证据：公司身份、报告年度/版本、PDF 物理页、原文区间或表格位置，以及该段落能支持的公司陈述范围。
- 法规证据：文件身份、条款、版本、发布日期及适用时间；事件日期未知或法规时间关系不清时标记 U/未知，不作强判。
- 问题与论断：哪些回答要点必须有年报证据、哪些规范性判断必须有法规依据，以及冻结的双库材料是否足以回答。
- 来源关系：引文是否确实支持对应论断、引用位置能否还原到输入文件、是否存在冲突或证据缺口。

区分“年报明确披露”“年报未提及”“当前候选池未找到”“明确否定”和“数据缺失”。报告未提及或抽取未命中不能当作零值、事件不存在或良好表现。年报自述只能支持“年报披露了该事项”；若问题要求确认外部事件实际发生，评测材料须另含相应原始来源。自动候选可帮助定位样例，不能直接充当最终标签。

## 5. 评价论断与引用核验

以实质论断为单位拆分评价，保存 claim_id、正文区间和需要的证据角色；对规范性评价建立 claim_id—fact_id—法规版本/条款链接。

分别核验：

- fact_supported：公司材料是否真实支持论断，是否存在捏造或矛盾。
- citation_exists：法规、版本、条款能否解析到真实来源。
- retrieved：引用是否在实际提供给模型的检索内容中。
- normative_supported：条文内容是否支持该规范性判断。
- temporally_applicable：在该事件日期是否适用；未知单独标注。
- evidence_status：supported / contradicted / insufficient / unresolved。
- answerability：冻结材料是否足以回答，用于评价回答或保留未判定是否恰当。

同一引用在 JSON 自报和正文重复出现时去重，但同一条款支持不同论断的边分别核验。真实但未召回的条文不是虚构引用；标题/条款号匹配不是语义支持。没有引用的输出仍核验实质论断，引用比例记 NA。

至少 120 条正式输出按维度、模式、可回答性和错误类型分层双人核验；隐藏模型/模式身份，记录随机种子、各层总量、抽样概率与权重。总体估计按抽样设计加权，难例分析另报。相同规范执行独立标注、一致性计算和仲裁。

旧版 citation_supported/fact_error 两字段保留历史含义；新增字段需扩展模板和评测加载，禁止将名称匹配自动填成全部语义支持。
