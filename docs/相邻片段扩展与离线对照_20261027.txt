本轮已实现及实测
================
本轮不需要可用大模型服务，未读取模型认证配置、未派发模型请求、未生成回答。
新增确定性同文档邻接选择器、原始年报来源区间核验、6种固定策略的离线比较、可复算指标和科学绘图。
结果保存在 results/runs/adjacent_evidence_development_20261027_02/。
它是8个已曝光开发问题的回归实验，不能作为新的独立留出验证或投稿录用证明。

实际比较设置
============
问题与初始检索均复用2026-10-23四家新公司×2023/2024两年度的8题。
每题初始上下文均重新检索并复现，初始提示也逐字一致。
每个方案上限6000参考tokens，使用同一冻结Qwen分词器，只作文本计数，不执行大模型推理。
所有补充阶段只追加完整已有片段，每阶段最多8个新来源；初始原文、来源记录和引用ID保留。

六个策略：
initial：原始上下文，不扩展。
fixed_preserve：沿用两轮共4条固定查询，保留已有材料再追加。
adjacent_rank：按原始年报种子顺序，先遍历全部直接后继，再遍历全部直接前驱。
adjacent_continuation：先同页后继、跨页后继、同页前驱、跨页前驱，各组内按原始种子顺序。
fixed_then_adjacent：先两轮固定查询，再按同页后继优先追加邻居。
adjacent_then_fixed：先按同页后继优先追加邻居，再两轮固定查询。

邻接只在同doc_id、股票代码、报告年度及PDF SHA256的坐标序列中取直接±1，排序为物理页码及原片段起点。
所有方案始终使用原始种子，不从新邻居递归扩展，也不跳过已存在邻居去寻找第二跳。
跨页邻居是已索引坐标序列的相邻节点，可能跨过空白或未入索引页；逐条审计保留physical_page_delta。
候选的0.0分只是兼容打包器的占位值，不是BM25相关性分数。
选择器不读取参考答案，不根据公司、日期或具体答案硬编码选择片段。
方案设计发生在检查过历史失败之后；没有预注册或盲测的主张。

===================================
初始材料HELD-600036-2024-P97-S0是物理第97页[0,1200)字符，最后截在“第十六次会议（5月14日”。
已有邻居HELD-600036-2024-P97-S1000对应同一页[1000,1706)，包含完整审计会议句[1079,1261)。

这些坐标是冻结PDFium文本的Unicode码点、左闭右开区间，不是PDF版面像素坐标。

离线复算
========
在xiaolun项目目录运行；需项目环境的tokenizers/jieba和本地pypdfium2。
直接可用pypdfium2的Python环境：
  python scripts/replay_adjacent_evidence_20261027.py --out-dir results/runs/adjacent_evidence_development_20261027_03

当前这台机器的项目Python没有直接安装pypdfium2。本次成功调用如下（PowerShell，既有bundled库追加到模块查找末尾，不安装或下载）：
  .venv-data/Scripts/python.exe -c "import sys,runpy;from pathlib import Path;sys.path.append(r'C:/Users/mech-mind/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/Lib/site-packages');sys.argv=[str(Path('scripts/replay_adjacent_evidence_20261027.py').resolve()),'--out-dir','results/runs/adjacent_evidence_development_20261027_03'];runpy.run_path(sys.argv[0],run_name='__main__')"

输出目录必须新建，脚本拒绝覆盖已有产物。脚本只读取冻结数据库/来源，不含调用大模型的路径。

仍可继续的离线工作及优先级
========================
1. 独立人工标注：请真实标注者分别核验全年成员并集、委员会列归属、会议次数与日期，并冻结分歧裁定；AI助手不能替代独立人类。
2. 年报表格结构和跨页续表解析：补足成员变更、出席表、多行姓名等结构信息，同时保留来源坐标；一跳邻居无法保证找到远离当前检索页的离任成员。
3. 新的冻结测试集：与这8题分开选公司/年度，固定问题与来源后再测，不把已曝光回归结果当泛化证据。
4. 有完整相关片段标注后评估真正的Recall@k、MRR、nDCG，以及按源位置匹配的证据Precision；现在缺少独立完整相关性标注，不应从页覆盖率反推。
5. 服务恢复后用相同题目、预算及提示开展生成比较，检验材料补全是否转化为回答指标改善。本轮没有运行这一步。
