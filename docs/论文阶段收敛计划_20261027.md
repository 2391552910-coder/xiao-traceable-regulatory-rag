### 复杂度判断与已发表论文参照

此前把跨模型 × 跨年度 × Agent × 表格解析同时纳入同一稿件的方案过于复杂：因素会相互混杂，也会把一篇“检验检索组织方式”的论文扩成多个独立贡献。当前收敛计划不是过度简化，而是把每个实验限制在它要支持的主张上。

可借鉴的发表范式并非都要求同等规模：

- **窄问题、强领域数据。**KBS 的短通信 *Retrieval augmented generation using engineering design knowledge* 主要研究专利描述中的显式关系识别/生成，并展示其在风机专利知识库中的 RAG 用法。其论文类型虽短，训练样例和知识库规模却很大；可借鉴的是贡献边界清晰，不是照搬其数据规模。
- **单一检索失效、少数对应干预。**INS 的 *Closing the acronym gap in educational retrieval with ontology-guided augmentation* 聚焦缩写导致的检索失败，比较查询时扩展、索引时增强及组合方案；以约一万份文档评估 Recall@k、nDCG@k、Success@k，并按查询做配对 bootstrap。对本项目最有用的是“一个失效原因—少数对照—匹配的检索指标”结构。
- **方法论文的高成本参照。**Neurocomputing 的 AIR-RAG 在六个基准上测试，包含多类强基线、17,811 条偏好样本和多组消融。它适合真正提出迭代检索/偏好学习新方法的论文，不是本项目当前阶段的最低门槛。

因此当前主稿按下列核心结构执行：固定现有语料、模型、提示和问题集；比较“双源分路检索”与“合并候选检索”；按问题配对呈现答案评分与证据供给结果，按公司聚类计算不确定性；保留缺失、失败与评分分歧。已存在的跨年度/Agent补充运行单独标注为小样本探索性结果，不与主实验混池，也不据此声称跨模型族泛化、时间迁移或 Agent 普遍优越。若以后要声称“检索 Precision/Recall/F1”，先为每题建立人工相关证据金标准；现有 0–8 分回答评分不能替代它。

仓库已有的 `data/annotation/reviews/independent_20261013/qrels.tsv` 含40题、1,049条候选相关性判断，标注来源为单审语义判断，且用途标为开发集；与当前主实验60题的题目ID交集为0。对应候选表没有检索名次或方法字段，标注池也不是穷尽金标准。因此不能据此为本稿60题主实验计算 Precision/Recall/F1，或把开发集判断外推为完整召回率。 主实验另保存60题、merged/dual两策略各Top-10的1,200条排序记录；排序存在，但缺少与这60题对齐的相关证据标注，因此仍不能计算主实验Precision@k、Recall@k或nDCG@k。

当前稿的中心问题限定为：在上市公司评价问答中，年报与法规分路检索相较于合并候选检索，是否改善现有任务的回答评分和证据供给？

当前主实验仍计划20家公司、60个问题、180个G1/G2/G3回答；实际供应商输出147个。全部检索和敏感性条件有355/400个可评分供应商回答。可配对样本中的G2−G1公司宏均分差为+0.228/8（41对，20,000次公司聚类bootstrap区间[0.110,0.355]）；但全题缺失界[-1.508,1.292]跨零，不能声称计划题集上有确定优势。历史G3−G2差−0.008也已由新分析+0.013/8（38对）取代。报告保留失败和评分分歧，并限定结论于现有样本、量表和模型设置。0–8分人工评分不是准确率；只有逐项人工金标准支持时，才报告Precision、Recall、F1或Accuracy。

### 发表论文做法对本项目的收敛建议（2026-10-28）

**判断：**旧计划确实过于复杂；当前计划已把问题收窄，但“跨年/Agent合并候选稿”仍会把投稿主线拉宽。建议主稿明确聚焦“在年报+法规问答中，双源分路检索相较合并候选检索是否改善回答得分及证据供给”。跨年和Agent实跑作为单独的探索性附录/后续论文素材；如果期刊字数压力或主线不突出，就从当前投稿正文移除，而不是继续给主稿加小实验。已完成的实验和文件保留，不重复跑，也不把它们删作未发生。

已发表研究呈现出三种不同的投入档位：

1. **与本项目任务最接近的年报问答路线。**Yang等的期刊论文 *Addressing investor concerns: a Chinese financial question-answering benchmark with LLM-based evaluation* 构建了13,643个投资者问题、516份2019–2022年报；由7名会计专业学生经培训标注，并用复核流程形成答案及页码证据。评测区分检索（NDCG/Hit/Recall）和答案内容分数，并使用按年度、按公司留出的切分。可借鉴的是“问题—人工参考答案—原文页码—检索和生成分开评测”的实验闭环。其规模大、人工标注成本高；本项目不用为了模仿而扩成万题，但若要声称Recall或证据支持率，应先给当前60题建独立相关证据金标准。
2. **小而聚焦的检索干预路线。**Alier等的 *Information Sciences* 论文只针对教育材料中的缩写检索失效，比较查询扩写、索引增强及组合，并用Recall@k、nDCG@k、Success@k及查询配对bootstrap回答该问题。借鉴其单故障、少数条件、指标对应主张的结构；不需要把Agent、跨年度、跨模型和复杂解析都列为主实验。
3. **高投入方法创新路线。**AIR-RAG（*Neurocomputing*）提出可训练适配器、两轮检索和偏好优化，在六个基准上与多类方法对照，另有17,811条偏好样本和消融。该论文的贡献是新检索算法与训练过程；本项目没有相当规模的模型训练贡献，因此不应把AIR-RAG的全部实验清单当作门槛。

据此，当前论文执行方案调整为：

- **主问题只保留一条。**核心比较以现有60题及通过来源核验的供应商输出为准：G1合并检索、G2双源分路检索；G3来源角色提示仅作次级诊断。排除助手会话补写后，主条件147/180、全条件355/400；G2−G1在41个可配对问题中的公司宏均分差为+0.228/8，缺失全题界跨零。维持公司内配对和公司聚类区间，报告效应量、区间和缺失/分歧，不将0–8人工量表包装为准确率。
- **拆开“回答质量”和“检索质量”。**回答质量沿用现有人工评分。检索只能报告现有日志确实能支持的描述性结果；Precision/Recall/F1、NDCG等需要先为同一题集建立独立人工相关页/证据标注并冻结判定规则。不得把回答评分或候选池单审标签代替qrels。
- **正文缩到一个贡献。**建议主文按问题、语料/题集、双源与合并检索条件、人工评测和配对统计、结果、误差与限制组织；跨年/Agent章节移到附录或后续研究，不与主实验汇总，不用图表数量补足证据。
- **补实验只补主张缺口。**若目标是现有范围内比较双源与合并检索，先完成剩余原始案例审计和主稿终审；若目标升级为跨年度/跨模型/Agent有效性，则另立独立测试集、预算配平和盲评协议后再做，不混入本稿“顺手补齐”。
