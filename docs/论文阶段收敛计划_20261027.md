# 当前论文执行计划

更新：2026-10-28

## 当前决定

**近期只收口现有双源 RAG 论文，不并行启动跨模型、跨年度、Agent 和表格解析新实验。**这些方向各自回答不同研究问题；只有当前论文的核心主张需要其中一项证据时，才单独启动对应验证。

### 复杂度判断与已发表论文参照

此前把跨模型 × 跨年度 × Agent × 表格解析同时纳入同一稿件的方案过于复杂：因素会相互混杂，也会把一篇“检验检索组织方式”的论文扩成多个独立贡献。当前收敛计划不是过度简化，而是把每个实验限制在它要支持的主张上。

可借鉴的发表范式并非都要求同等规模：

- **窄问题、强领域数据。**KBS 的短通信 *Retrieval augmented generation using engineering design knowledge* 主要研究专利描述中的显式关系识别/生成，并展示其在风机专利知识库中的 RAG 用法。其论文类型虽短，训练样例和知识库规模却很大；可借鉴的是贡献边界清晰，不是照搬其数据规模。
- **单一检索失效、少数对应干预。**INS 的 *Closing the acronym gap in educational retrieval with ontology-guided augmentation* 聚焦缩写导致的检索失败，比较查询时扩展、索引时增强及组合方案；以约一万份文档评估 Recall@k、nDCG@k、Success@k，并按查询做配对 bootstrap。对本项目最有用的是“一个失效原因—少数对照—匹配的检索指标”结构。
- **方法论文的高成本参照。**Neurocomputing 的 AIR-RAG 在六个基准上测试，包含多类强基线、17,811 条偏好样本和多组消融。它适合真正提出迭代检索/偏好学习新方法的论文，不是本项目当前阶段的最低门槛。

因此当前稿按下列最小结构执行：固定现有语料、模型、提示和问题集；只比较“双源分路检索”与“合并候选检索”这两个条件；按问题配对呈现答案评分与证据供给结果，按公司聚类计算不确定性；保留缺失、失败与评分分歧。当前样本不支持跨模型、跨时间泛化或 Agent 优越性结论。若以后要声称“检索 Precision/Recall/F1”，先为每题建立人工相关证据金标准；现有 0–8 分回答评分不能替代它。

仓库已有的 `data/annotation/reviews/independent_20261013/qrels.tsv` 含40题、1,049条候选相关性判断，标注来源为单审语义判断，且用途标为开发集；与当前主实验60题的题目ID交集为0。对应候选表没有检索名次或方法字段，标注池也不是穷尽金标准。因此不能据此为本稿60题主实验计算 Precision/Recall/F1，或把开发集判断外推为完整召回率。

当前稿的中心问题限定为：在上市公司评价问答中，年报与法规分路检索相较于合并候选检索，是否改善现有任务的回答评分和证据供给？

现有主实验为20家公司、60个问题、400个计划回答单元，其中386个有有效的双人评分。已观测配对中，双路相对合并检索的公司宏均分差为+0.250/8，探索性95%公司聚类区间为[0.167, 0.333]；相同上下文下的来源角色提示差为−0.008，未显示稳定增益。报告必须保留失败和评分分歧，并将结论限定在现有样本、量表和模型设置内。0–8分人工评分不是准确率；只有逐项人工金标准支持时，才报告 Precision、Recall、F1 或 Accuracy。

## 近期只做三项

1. **完成主稿证据对齐。**逐项核对正文数字、400个计划单元与386份有效评分、失败输出、评分规则、统计结果和图表；不把386份输出当作386个独立公司样本，不把后验分析写成预注册确认性结论。
2. **按现稿边界收窄主张；论断级复核暂不作为冻结门槛。**主稿已明确说明位置/引用编号不等于论断语义支持，历史法规时点适用性未获独立验证，也不把模型自报 `supported` 当真实性标签。因此，40题、120条回答的论断—证据盲审包是可选补充研究，不阻塞当前主稿冻结；只有将来要提出论断级支持率或法规时点正确性主张时，才由真实复核者独立填写并仲裁。不能用脚本或模型自评代替人工判断。法规版次接收报告中的92条仍是待仲裁字段文本差异，不是已确认的实质冲突；接受标签为0，审阅人身份和盲审均未验证。
3. **冻结可复核稿件。**统一中文主稿、英文稿、统计表、附录和复现说明中的数字、引文、方法边界与局限；核对作者和投稿元数据后再按目标期刊格式整理。篇幅、表格和图片数量不能替代证据质量，也不能保证分区或录用。

## 暂缓方向与重启条件

- **跨模型族：**只有在论文提出模型依赖或泛化主张，且第二个服务/模型能保存可比请求、响应和版本身份时再做。
- **跨年度：**只有在主张时间迁移时再做；既有4家公司留出数据已暴露并有事后标签修订，不作为干净测试集。
- **Agent：**只有在主张迭代决策有效时再做；必须与单模型自检按相同总调用/token预算比较，并对新回答做人工盲评。
- **年报表格与续表解析：**作为独立研究支线。现有工作已完成离线工程实现及开发集非回归检查，但独立人工验证和新生成回答质量尚未完成；不并入当前双源主稿。
- **法规时点：**当前语料包含晚于2024报告期的版本。稿件已说明这只是版本风险，不能据此认定具体法规不适用，也不能宣称已验证历史时点正确性。
