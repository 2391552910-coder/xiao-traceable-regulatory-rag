本轮实现
========
src/generation/evidence_budget.py：将表格和直接邻接候选放入同一预算分配流程。
1. 输入来自同一个冻结候选池；表格为固定top24类型均衡检索，邻接由原始种子的单跳选择器产生。
2. 只查看种子文本末尾的字面线索：未闭合的日期括号、未完成的中文日期、可能未完成的数字日期。
3. 只有直接同页后继可因上述线索优先；完整年月日和已闭合的日期括号不会仅因日期存在而被优先。
4. 不读取参考答案，不按公司、年份、页码或某个正确姓名硬编码，不生成检索查询。
5. 初始文本、来源记录和引用ID完整保留，新增材料只追加完整块，不截断、不重编号原证据。
6. 统一6000参考tokens、最多16个新增来源；逐条尝试，每次最多追加1条，满足既有每次最多8条限制。
7. 所有候选先验证公司/年度/PDF、有限分数、表格字段绑定和邻接选择器记录；即使候选因预算放不下，也不允许错误来源混入池中。
8. 截断线索是排序启发，不等于相关性或语义支持的证明。跨页、其他委员会、其他年度的材料不能因启发而越过来源范围。

预定的5种策略
=============
initial：不扩展，保留原始材料。
table_first：先所有表格候选，再邻接候选。
adjacent_first：先所有邻接候选，再表格候选。
boundary_first：先有截断线索的同页后继，再表格候选，最后其他邻接候选。
boundary_round_robin：先有截断线索的同页后继，再交替安排表格和其他邻接候选。
五种策略共用相同问题、候选池、预算和来源总上限，均完整报告，不选择性删去负例。

交替安排虽然补回日期，却只保留3个表格姓名候选；邻接优先只保留2个。负例保留在逐题结果、图和验收记录中。
这只证明当前开发案例的材料供给得到协调，不能证明大模型会正确抽取，也不能保证未知版式或新公司有效。
该案例的日期来源区间来自既有AI助手事后核查，不是独立人类金标准。

新增的API与命令
===============
Python接口：
  from src.generation.evidence_budget import allocate_evidence_budget
  final_context, audit = allocate_evidence_budget(question, initial_context, table_hits, adjacent_hits, adjacent_audit, counter, policy='boundary_first')

在xiaolun项目根目录导出联合材料（输出目录必须全新）：
  .venv-data/Scripts/python.exe scripts/supplement_evidence_budget.py --packet results/paper/heldout_validation_20261023_01/packets/NEW-600036-2024-AUDIT.json --table-index results/runs/annual_table_development_20261027_03/table_index.sqlite --window-index results/paper/heldout_validation_20261023_01/index_pdfium.sqlite --out-dir results/runs/my_joint_packet
默认boundary_first；可用 --policy 指定其余4策略。
默认分词器来自本机冻结计划；其他机器可用 --tokenizer 和 --tokenizer-sha256 指向同一个参考分词器。初始材料也必须使用同一计数口径。

重新构造40份材料（选新目录，不覆盖01/02）：
  .venv-data/Scripts/python.exe scripts/run_evidence_budget_development_20261027.py --out-dir results/runs/evidence_budget_development_20261027_03
核对当前01与02批次：
  .venv-data/Scripts/python.exe scripts/audit_evidence_budget_development_20261027.py
重绘当前主批次：

主要输出
========
offline_protocol.json：策略、预算、事先规划、代码和输入哈希。
candidate_pools/：每题相同候选池及哈希、邻接选择器证明记录。
contexts/：40份最终材料、所有候选的接受/省略原因、来源和引用记录。
contexts_saved_before_reference_analysis.json：分析参考内容前的40文件收据。
offline_analysis.json / offline_metrics.csv：全部策略与逐题材料供给指标。
source_verification.json：原PDF、原窗口、PDFium重解析及表格来源沿用说明。
tests_passed.xml / implementation_audit.json：240项测试、逐字节重复性和历史不变性。
figures/joint_source_supply.png / .svg：含所有策略的双源供给/预算对照图。
