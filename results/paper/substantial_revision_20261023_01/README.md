## 研究范围与结果边界

主稿基于20家公司、60个问题的既有研究。400个计划输出中有386个有效输出接受两位评分者评分。既有结果显示，双路检索G2相对合并候选池G1的已观测公司宏均差为+0.250；同上下文角色提示G3相对G2为−0.008，未显示稳定增量。另含1,800个缓存候选上下文回放和600个新BM25上下文诊断；它们没有产生新的模型回答。

新增检索和统计分析为后验探索。参考页面覆盖、来源编号可解析和词面重叠都不等于论断语义支持或法规时点适用。跨模型族泛化、法规版本适用性和逐论断独立语义核验尚未完成；作者、单位、基金及投稿声明仍需据实补齐。篇幅、图片数量与期刊分区不构成录用保证。

压缩包中的复算脚本依赖项目已有冻结输入与 `src` 模块，不是脱离仓库即可独立运行的数据集。详细输入、输出及哈希见交付说明和清单。
