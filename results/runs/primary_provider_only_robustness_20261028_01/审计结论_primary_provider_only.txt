4. Page references are human-adjudicated physical pages; chunk/page overlap is not semantic support or exhaustive retrieval recall.

6. The main alias k3 has no independently verified provider model revision; temperature=1, one repeat per condition.
7. API recovery outputs are explicitly merged first valid outputs, not extra samples; first-attempt and recovered results must remain separate.

9. Only 355 two-reviewer-scored outputs from the recorded provider-generation runs enter this filtered analysis; the original 386-score analysis remains preserved as a superseded historical artifact.
10. Source-removal conditions reduce available context information and token count jointly; they establish necessity under this setup, not a purely role-label causal effect.
11. NoRerank and BM25 observed quality exceed G3, so claims that dense retrieval, reranking or role constraints are uniformly superior are unsupported.
